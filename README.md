# Monk Watch - Naga Procession (เด็กวัดเฝ้าขบวนนาค)

เกม Text-based Anomaly Spotting แนว Psychological Horror ธีมงานศพไทย
ผู้เล่นรับบทเป็นเด็กวัดที่ต้องสังเกตความผิดปกติของขบวนนาค

## วิธีเล่น
1. ติดตั้ง Pygame: `pip install pygame`
2. รันเกม: `python main.py`
3. กด `N` (ปกติ) หรือ `A` (ผิดปกติ) เพื่อตัดสินใจ

## เทคโนโลยี
- Python 3
- Pygame
